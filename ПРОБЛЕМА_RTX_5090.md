# RTX 5090 и PyTorch — РЕШЕНО

## Статус: Полная поддержка

RTX 5090 (архитектура Blackwell, compute capability sm_120) **полностью поддерживается** в PyTorch 2.7+ и bitsandbytes 0.43+.

Поддержка работает на **Windows и Linux**.

## Установка

### 1. Установите PyTorch с CUDA 12.8

```cmd
pip uninstall torch torchvision torchaudio
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128
```

### 2. Установите Monocle

```cmd
pip install -r requirements.txt
python -m pip install .
```

### 3. Проверьте работу GPU

```cmd
python -c "import torch; print('CUDA:', torch.cuda.is_available()); print('GPU:', torch.cuda.get_device_name(0)); x = torch.rand(5, 3).cuda(); print('Test:', x * 2)"
```

Ожидаемый вывод:
```
CUDA: True
GPU: NVIDIA GeForce RTX 5090
Test: tensor([[...], ...], device='cuda:0')
```

## Требования

| Компонент | Минимальная версия |
|-----------|-------------------|
| PyTorch | >= 2.7.0 |
| CUDA Toolkit | >= 12.8 |
| bitsandbytes | >= 0.43.0 |
| NVIDIA Driver | >= 566.03 |

## Если GPU не работает

Если при запуске вы видите ошибку `no kernel image is available for execution on the device`:

1. Проверьте версию PyTorch: `python -c "import torch; print(torch.__version__)"`
   - Должна быть >= 2.7.0
2. Проверьте CUDA-версию PyTorch: `python -c "import torch; print(torch.version.cuda)"`
   - Должна быть >= 12.8
3. Если версия старая — переустановите:
   ```cmd
   pip uninstall torch torchvision torchaudio
   pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu128
   ```

## Производительность RTX 5090

С полной поддержкой GPU и 4-bit квантизацией:

| Модель | VRAM | Скорость |
|--------|------|----------|
| Mistral-7B (4-bit) | ~4-5 GB | ~2-3 сек/функция |
| Qwen2.5-Coder-14B (4-bit) | ~8-10 GB | ~4-6 сек/функция |
| Qwen2.5-Coder-32B (4-bit) | ~18-20 GB | ~8-12 сек/функция |

32 GB VRAM RTX 5090 позволяет запускать даже 32B модели с запасом.
